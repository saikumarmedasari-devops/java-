# E-Commerce Testing Project

## Project Description
A Java-based E-Commerce Order Management System with automated testing and CI/CD.

## Technologies
- Java 21
- Maven
- JUnit 5
- GitHub Actions
- Checkstyle
- OWASP Dependency-Check

## Project Structure
```text
ecommerce-testing/
├── src/
│   ├── main/java/
│   └── test/java/
├── pom.xml
├── README.md
└── .gitignore
```

## How to Run Tests

```bash
mvn clean test
```

## CI/CD Pipeline

GitHub Actions automatically performs:

1. Build
2. Test
3. Code Quality
4. Security Scanning

## Project Goal
To demonstrate Java development, automated testing and DevSecOps practices.
